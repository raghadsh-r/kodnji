# My Personal Portfolio Website
A simple and elegant personal website built to introduce myself, my skills, and my journey in the field of Artificial Intelligence. This project was created as part of my self-learning journey to master front-end development.

✨ Features
About Me Section: A brief introduction to my background as a student at JUST.

Responsive Design: Styled using custom CSS for a clean look.

Project Showcases: (Optional) Links or descriptions of my robotics and AI projects.

🛠️ Technologies Used
HTML5: For the structure of the website.

CSS3: For styling and layout.

GitHub Pages: (If you host it) To make the website live and accessible.

📁 Project Structure
index.html: The main homepage.

style.css: The stylesheet containing all the visual designs.

/assets: Directory for images and media.

🌟 Learning Goals
This was my first step into web development. Through this project, I learned:

How to structure web content.

The basics of CSS styling and positioning.

How to deploy a website on GitHub.
